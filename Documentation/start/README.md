# Start here

*Installation, the one mandatory configuration step, and a check that the plugin really did build.*

The plugin installs from Fab, compiled for your engine version, or manually from source into your project.

Start with Quick start for a working example without the details, then read Installation, Configuration, and Verification in that order.

## Pages in this section

| [Configuration](configuration.md) | One mandatory step, two optional ones — and a list of everything that works without any configuration.                                     |
| [Verification](verification.md) | Three checks — from the presence of a menu entry to a manual broadcast that helps you determine whether the problem is on the sender or receiver side.   |
